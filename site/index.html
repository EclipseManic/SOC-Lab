Why document misses?

A missed detection is the most useful artifact in the lab. It shows exactly which log source, rule, or field mapping needs work, and it becomes a retest item instead of an untracked weakness.

Analyst workflow

The same six moves for every case

  1. 01
    Alert

    Identify the signal and its source.

  2. 02
    Triage

    Decide what is real and how urgent it is.

  3. 03
    Scope

    Find the first host, account, and timestamp.

  4. 04
    Collect

    Preserve logs, processes, files, and network evidence.

  5. 05
    Verdict

    State what happened and what is still unknown.

  6. 06
    Report

    Turn the evidence into a defensible timeline.

Plain English

The terms you need, without the jargon.

Suricata

Network detection software. It inspects traffic crossing the gateway and raises an alert when it recognises a suspicious pattern.

Wazuh

The SIEM. It collects logs from hosts, correlates them, and makes alerts searchable in one place.

TheHive

Case management. It turns an alert into a structured investigation with tasks, observables, and a timeline.

Kerberoasting

An attack that requests encrypted service tickets, then cracks them offline to recover a service account password.

DCSync

An attack that impersonates a domain controller to copy password hashes from Active Directory.

Pass-the-Hash

Logging in with a stolen password hash instead of the plaintext password.

Golden Ticket

A forged Kerberos ticket that gives long-lived access to the domain, created with the KRBTGT key.

Detection gap

The telemetry exists, but no rule covers the behavior. A logging gap means the telemetry was never collected.

SOC//LAB

An authorized, isolated lab. Every action was performed against systems owned by the author. No production data, live credentials, or public targets are included.
